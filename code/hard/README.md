# Code / Hard

The hard tier is Python's object model and runtime: descriptor protocols with `__get__`/`__set__`, metaclasses and custom `__call__`, MRO in diamond inheritance, late-binding closures, async context managers, thread-safety and the GIL, decorator metadata without `functools.wraps`, singletons via `__new__` vs metaclasses, generator exhaustion, shallow vs deep copy. Questions are still behavior questions — "what does this print," "is this correct" — but answering correctly requires simulating machinery most programmers never trace by hand. Records run 4–5 think blocks (~552 words on average) and close with 60–150-word final answers that carry the key insight (~96 words on average). In the 3×3×3 grid this tier teaches effort-matching from the top: deep semantics earn multiple rounds of catching, fixing, and verifying before an answer is allowed to stand.

## What "hard" code looks like

The first attempt commits to a reading that is wrong *in an interesting way*: trusting a misleading function name over the actual comparison operator; assuming a closure captures the loop variable's value at definition time; treating a decorator's wrapper as if it preserved the original's `__name__`; believing a singleton via `__new__` and one via metaclass are interchangeable; reading a class attribute mutation as per-instance; expecting a generator to restart after exhaustion. Blocks 2–3 catch and repair; blocks 4–5 verify by genuinely different methods — a hand-trace of the C3 linearization, a `type(...)`/`isinstance(...)` probe, an equivalent explicit-loop version run against the generator, a data-descriptor precedence check against the instance `__dict__`. Doubts at this tier are deep and get rejected against the language spec rather than gut checks: "type hints make Python gradually typed," "asyncio must use threads to be concurrent," "`__getattr__` intercepts every attribute access," "surely CPython optimizes tail calls."

## The easier tiers

Hard is where the three modes stretch furthest apart: a wrong first block costs two more blocks of repair, and a confirmed answer can accumulate four independent verifications. [Code / Medium](../medium/README.md) carries the same contract at 3 blocks against semantics traps; [Code / Easy](../easy/README.md) compresses it to 1–2 blocks against careless errors. Difficulty changes the depth of the reasoning, never whether the reasoning happens.
